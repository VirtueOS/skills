## What it does

Sharpen an idea with a sequential interview. This entry point is stateless: it saves no project documentation.

## When to reach for it

Invoke this explicitly. Invoke grill-me for a plan or idea without a project documentation trail; use grill-with-docs when working in a repository.

## Common questions

**Does it ask all questions up front?**

No. It loads grilling, which asks one question at a time.

**What if words cannot settle a design question?**

Use a small prototype, observe it, then return to the interview.

## It's working if

- The next question uses your previous answer.
- You leave with a clear agreed scope.
