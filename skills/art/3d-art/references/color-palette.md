# Work with the project's palette

Read this when selecting or revising colors, then view the relevant approved images and current project assets. Determine which references define color relationships, which define geometry, and which depict the exact asset to match. Follow [art-direction guidance](art-direction.md) for the wider visual brief.

Extract the dominant materials, accent distribution, saturation, temperature, and functional color meanings from the approved sources. Use provided swatches or material values when available; do not invent exact HEX values from an uncalibrated image. A palette reference does not authorize recoloring unrelated existing assets.

Images contain lighting, shadows, reflections, and exposure. Distinguish those effects from intrinsic color before editing albedo. Preserve the project's chosen surface treatment and texture variation, whether painterly, realistic, or otherwise. Clarify a missing palette only when the task and neighboring assets leave a material choice unresolved.

Compare an existing tile and its revision side by side under the same Godot camera, light, and exposure. Judge corresponding base-material regions separately from decorations. Account for sRGB/linear conversion when calculating color changes. Preserve authored variation rather than chasing average RGB alone.
